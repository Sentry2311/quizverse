# QuizVerse — Online Quiz Platform

A responsive online quiz platform built with React, Vite, and Tailwind CSS.

## Features
- Responsive student dashboard and quiz catalogue
- Interactive five-question JavaScript quiz with answer navigation and countdown timer
- Automatic scoring and result screen
- Quiz attempts persist in browser local storage
- Leaderboard UI and mobile navigation

## Run locally
```bash
npm install
npm run dev
```

## Technology
React, Vite, Tailwind CSS, Lucide React.

## Note
This is a front-end academic project. Quiz data and results are stored locally in the browser; no external database or authentication server is used.
